THE EXPERIENCE

Moderation that feels like part of your stream.

The extension separates ban events from timeout cells so each system can do its job without getting in the other's way. A queued ban does not create its animation early: when its turn arrives, the whole event starts together from the beginning.

Independent ban queueBan events wait as data until the previous ban scene has fully cleared.
Independent timeoutsTimeout cells continue running and stacking without waiting for bans.
Complete ban arrivalTruck, message, sound, skid marks and animation begin together.

SETUP GUIDE

Get the widget running.

Install the RTS UI DLL, import the Streamer.bot actions, add the overlay to OBS, then configure the widget settings.

  1. Install the current Road to Somewhere UI DLL from the dedicated DLL page.
  2. Open Streamer.bot and use Import to paste the import string above, or download the exact versioned import file.
  3. Enable the imported actions and verify the extension's settings action is available.
  4. Add the hosted overlay URL to an OBS Browser Source, or use the local overlay ZIP.
  5. Open the extension settings and configure the presentation for your stream.
  6. Run a test ban and timeout before putting it live.
