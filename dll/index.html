THE ROAD TO SOMEWHERE / CORE

The UI layer behind
the journey.

The Road to Somewhere UI DLL provides the shared settings and interface tools used by our Streamer.bot extensions. It gives each extension a consistent, approachable way to configure the things that make your stream yours.

VERSION 1.0.0Streamer.bot UI library
WHAT IT DOES

One settings experience across the extensions.

Our extensions are built to do more than run actions. The UI DLL provides the settings layer that lets you configure them without digging through actions, arguments or source code.

Simple settingsConfigure extension options through a dedicated UI.
PersistentYour settings stay with you when extensions are updated.
ConsistentA familiar settings experience across The Road to Somewhere.
Built for creatorsClear controls designed around real streaming workflows.

INSTALLATION

Get the DLL into Streamer.bot.

Install the library once and the extensions that depend on it can use the shared settings system.

  1. Close Streamer.bot before installing or updating the DLL.
  2. Download the current DLL from the button below.
  3. Open your Streamer.bot installation folder and locate the dlls folder. Create it if needed.
  4. Copy the DLL into the dlls folder. Replace an older version if one is already there.
  5. Start Streamer.bot again. Your Road to Somewhere extensions can now use the UI library.
Important: Keep only one copy of the DLL in your Streamer.bot installation. Multiple copies can cause confusing loading behaviour.
