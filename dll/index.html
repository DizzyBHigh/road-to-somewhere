THE ROAD TO SOMEWHERE / CORE

The UI layer behind
the journey.

The Road to Somewhere UI DLL is shared infrastructure for our Streamer.bot extensions. Install it once and extensions can use the same settings experience without each product carrying its own copy.

VERSION 1.0.0Shared Streamer.bot UI component
WHAT IT DOES

One settings experience across the extensions.

The DLL provides the shared settings layer used by Road to Somewhere extensions. It keeps configuration consistent and gives each extension a dedicated interface rather than pushing users into raw action arguments.

Simple settingsConfigure extension options through a dedicated UI.
PersistentKeep configuration available across extension updates.
ConsistentA familiar settings experience across Road to Somewhere.
Shared dependencyInstall once and use it with supported extensions.

INSTALLATION

Install the shared UI once.

You do not need to install the DLL separately for every extension. Keep one current copy in your Streamer.bot installation.

  1. Close Streamer.bot before installing or updating the DLL.
  2. Download the current DLL from this page.
  3. Open your Streamer.bot installation folder and locate the dlls folder. Create it if needed.
  4. Copy the DLL into the dlls folder, replacing an older version if present.
  5. Start Streamer.bot again. Supported Road to Somewhere extensions can now use the shared UI.
Important: Keep only one copy of the DLL in your Streamer.bot installation. Multiple copies can cause confusing loading behaviour.
