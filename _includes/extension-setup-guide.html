SETUP GUIDE

Get the extension running.

Import the Streamer.bot actions, enable them, add the overlay to OBS, then test the extension.

  1. Import the Streamer.bot actions Open Streamer.bot and use Import to paste the supplied import string, or download the exact versioned import file.
  2. Enable the imported actions Enable the imported RTS actions so the extension can respond to events.
  3. Add the extension overlay to OBS Add the extension's hosted overlay URL as an OBS Browser Source, or use the supplied local overlay files.
  4. Test the extension Run a test event and confirm the overlay responds correctly before putting it live.
